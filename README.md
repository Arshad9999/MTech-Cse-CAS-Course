# M.Tech CSE at CAS — Course Companion

[**Open the course home page**](https://arshad9999.github.io/MTech-Cse-CAS-Course/)

An independent study companion for the Centre for Advanced Studies (CAS), AKTU M.Tech Computer Science and Engineering programme. It organises the [2021–22 programme syllabus](https://cas.res.in/pdf/CSE-Syllabus%202021-22.pdf) by semester, common core, specialisation and elective. Your batch's current scheme may differ; confirm requirements with the department.

The site links to five existing detailed guides. The selected featured courses have topic notes, and five include the earlier detailed guides and visuals. Other course pages link to the official syllabus. Some pages include paraphrased questions and explanations from related AKTU M.Tech papers, identified by their actual course and year; these are not represented as CAS-specific papers. Some existing guides contain older course labels or credit values. The directory follows the 2021–22 semester tables, which themselves contain some inconsistencies.

## Course folders

Each course has a folder and a README with its programme details and website link. Elective subjects listed are choices, not a list of courses every student must take.

## Run locally

```bash
npm ci
npm run build
python3 -m http.server 8000
```

Open http://localhost:8000. A web server is required because the pages load shared data using `fetch`.

## Project structure

- `index.html` and `subject.html` provide the programme directory and subject pages.
- `assets/catalog.json` holds semester, course, specialisation and syllabus references. `assets/course-data.json` and `assets/course-supplements.json` hold the five detailed guides.
- Each course folder contains a README. Existing guides also contain an `index.html` and PDF.
- `assets/styles.css`, `assets/portal.css` and `assets/mastery.css` define the interface. The home page uses Framer Motion and an adapted MicroKit gradient underline component, listed by 21st.dev. See `third-party/MICROKIT-LICENSE.txt`.
- `.github/workflows/pages.yml` validates and deploys the site on pushes to `main`.

## Validation

Install `pypdf`, then run `python3 scripts/validate.py`. It checks the catalogue, existing course materials, local HTML links, topic coverage and PDF page counts.
