# M.Tech CSE at CAS — Course Companion

[**Open the course home page**](https://arshad9999.github.io/MTech-Cse-CAS-Course/)

An independent study companion for the Centre for Advanced Studies (CAS), AKTU M.Tech Computer Science and Engineering programme. It organises the [2021–22 programme syllabus](https://cas.res.in/pdf/CSE-Syllabus%202021-22.pdf) by semester, common core, specialisation and elective. Your batch's current scheme may differ; confirm requirements with the department.

The site links to five existing detailed guides. The selected featured courses have topic notes, and five include the earlier detailed guides and visuals. Other course pages link to the official syllabus. Some pages include paraphrased questions and explanations from related AKTU M.Tech papers, identified by their actual course and year; these are not represented as CAS-specific papers. Some existing guides contain older course labels or credit values. The directory follows the 2021–22 semester tables, which themselves contain some inconsistencies.

## Run locally

```bash
npm ci
npm run build
python3 -m http.server 8000
```

Open http://localhost:8000. A web server is required because the pages load shared data using `fetch`.

## Project structure

- `index.html` and `subject.html` provide the semantic programme directory and subject pages.
- `manifest.json` and `sw.js` enable offline-first Progressive Web App (PWA) caching for campus access.
- `data/courses.json` provides structured course telemetry: semesters, credits, unit breakdowns, domain classification, and PYQ availability.
- `assets/css/` contains modular stylesheets:
  - `tokens.css`: Editorial typography, spacing, light/dark colours, and domain colour accents.
  - `components.css`: Sticky filter ribbon, tactile receipt-style Study Docket drawer, examination planner, and 2-axis matchmaker.
  - `print.css`: Clean A4 print rules for physical revision timetables and dossiers.
- `assets/js/` contains modular application logic:
  - `app.js`: Main controller, catalogue rendering, live search/filtering, and telemetry.
  - `study-docket.js`: Docket state management (`localStorage`), RFC 5545 `.ics` iCalendar timetable export, and zero-dependency client-side SVG QR code generator.
  - `matchmaker.js`: Interactive 2-axis elective explorer (Theory ↔ Systems vs. AI/Data ↔ Security/Networks).
  - `command-palette.js`: Global fuzzy search modal (`Ctrl+K` / `/`) jumping across subjects, units, and official syllabus links.
- `guides/index.html` indexes interactive mastery hubs and postgraduate study resources.
- `.github/workflows/pages.yml` validates and deploys the site on pushes to `main`.

## Validation

Install `pypdf`, then run `python3 scripts/validate.py`. It checks the catalogue, existing course materials, local HTML links, topic coverage and PDF page counts.

## Interactive Examination Tools

- **Unit-by-Unit Topic Filtering:** Switch between syllabus units to focus on specific modules.
- **Interactive Self-Assessment Quizzes:** Step-by-step immediate solution feedback for each question.
- **GeeksforGeeks (GFG) Curated Vault:** Mapped tutorials and implementations for interview & lab readiness.
- **Study Docket:** Save subjects to your revision queue, calculate preparation pacing, and export iCalendar (.ics) revision milestones.
